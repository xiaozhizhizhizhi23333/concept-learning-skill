# programming/ — 编程学习板块

这是我在《统计与数据分析》课程作业之外，自己延伸出来的**编程学习记录**。

我在 2026 年 9 月定下了「**Python → 数据分析与可视化**」的学习路线，这个目录用来存放学习计划、环境配置和每一周的练习记录 —— 让学习过程本身也变成一份可回看的作品。

## 学习路线

| 阶段 | 周次 | 目标产出 |
|---|---|---|
| 打基础 | 第 1–2 周 | 判断类小程序（成绩等级、BMI 判定） |
| 会组织 | 第 3–5 周 | 能批量处理数据的小工具 |
| 玩数据 | 第 6–10 周 | 一份「数据 + 图表」小报告 |
| 做项目 | 第 11–14 周 | GitHub 上一个别人能看到的作品 |

**每周节奏**：6 天 × 25 分钟，周日休息。周一学、周二改、周三周四练、周五自己挑战、周六整理上传。

选这条路的原因：它和《统计与数据分析》课程是同一套技能，作业可以互相复用；广告与营销岗位现在最需要「会看数据、能做图表」的人；而且 Python 也是后续接触 AI 应用的同一门语言。

详细安排见 [`learning-plan.html`](./learning-plan.html)（用浏览器打开，可勾选打卡，进度存在本地）。

## 怎么用这些 notebook

1. 用 VS Code 打开本目录（或整个仓库）。
2. 打开 `notebooks/` 下的 `.ipynb` 文件。
3. 第一次要点右上角**「选择内核」→ 选 `Python 3.12`**。
4. 点代码块左侧的 ▶ 就能运行。

环境损坏或换电脑时，按 [`environment-setup.md`](./environment-setup.md) 重建即可。

## 关于「人工核查」

这个目录里的所有材料都由 AI 协助整理，但我做了逐项核查：

- **`environment-setup.md` 中的每一条结论都经过实测**，不是照搬 AI 的说法。比如「系统里只有一个 Python 版本」是查了 PATH 解析结果 + 注册表卸载项 + 常见安装目录三处才确认的；「.ipynb 可用」是真的用命令行把 notebook 跑了一遍、检查了输出内容（含图表 PNG 是否生成），而不是「打开看一眼觉得没问题」。
- **`notebooks/第1周练习.ipynb` 里的参考答案全部实际运行验证过**，包括边界值（BMI 分别取偏瘦/正常/偏胖三档测试）。
- **遇到报错时记录了问题和最终解决方式**，写在 `environment-setup.md` 第四节，供以后自查。
